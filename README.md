# Hattama — протокол совещаний с контролем поручений

Система принимает запись совещания и выдаёт официальный протокол и список поручений
с ответственными, сроками и статусами. Работает полностью локально, без передачи
аудио и текста во внешние сервисы — решение рассчитано на закрытый контур заказчика.

## Проблема

На совещаниях поручения раздают устно. Секретарь записывает их вручную: часть теряется,
сроки искажаются («до конца недели» превращается в «до пятницы»), ответственный
не всегда зафиксирован. Через неделю никто не может сказать, кому что поручено.
Протокол оформляют ещё два-три часа после встречи, а исполнение не контролируется,
потому что контролировать нечего — списка нет.

## Что делает система

1. Расшифровывает запись — русский, казахский, смешанная речь.
2. Разделяет говорящих и подставляет их имена из контекста разговора.
3. Извлекает поручения: что сделать, кому, к какому сроку, кто поручил,
   и прикладывает точную цитату из стенограммы.
4. Переводит устные сроки в даты: «до конца недели» → 25.09.2026,
   рядом сохраняется правило пересчёта.
5. Собирает протокол в DOCX и ведёт таблицу поручений со статусами
   «в работе / просрочено / выполнено».

## Архитектура

```
аудио → ffmpeg (16 кГц моно)
      → whisper.cpp large-v3-turbo         распознавание речи, локально
      → разделение говорящих по паузам     + подстановка имён из контекста
      → Ollama qwen3:4b                    извлечение поручений в JSON
      → нормализация сроков (код, не модель)
      → SQLite                             хранение и статусы
      → FastAPI                            API и веб-интерфейс
      → python-docx                        протокол в DOCX
```

Сроки переводятся в даты обычным кодом, а не моделью: правило должно быть
одинаковым каждый раз и объяснимым.

## Используемые технологии

- whisper.cpp + модель ggml-large-v3-turbo — распознавание речи на видеоядре Apple Silicon
- Ollama + qwen3:4b — извлечение поручений, локально
- FastAPI, SQLite, python-docx
- Веб-интерфейс без сборки: один HTML-файл

Внешние облачные API не используются: это требование кейса о закрытом контуре.

## Установка

Требуется macOS с Apple Silicon, 8 ГБ свободного места, Homebrew.

```bash
brew install ffmpeg ollama whisper-cpp
ollama serve &
ollama pull qwen3:4b

mkdir -p ~/Desktop/models
curl -L -o ~/Desktop/models/ggml-large-v3-turbo.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin

python3 -m venv .venv
./.venv/bin/pip install fastapi uvicorn python-docx requests python-multipart
```

## Запуск

```bash
./.venv/bin/python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Открыть http://localhost:8000

## Проверка основного сценария

1. Открыть http://localhost:8000
2. Загрузить `samples/meeting_test.wav` и нажать «Разобрать запись»
3. Дождаться статуса «готово» — появится таблица поручений
   с ответственными, сроками и цитатами из стенограммы
4. Нажать «Скачать протокол (DOCX)»

Ожидаемый результат: поручения с ответственными и сроками,
переведёнными в даты, протокол в формате DOCX.

## Структура

```
backend/     распознавание, извлечение поручений, даты, экспорт, API
frontend/    веб-интерфейс
samples/     демо-запись и стенограмма
docs/        развитие продукта
```

## Ограничения

- Разделение говорящих работает по паузам между репликами: на перебивках
  возможны ошибки, менеджер правит ответственного вручную.
- Качество распознавания казахской речи ниже русской: модель turbo ужата
  ради скорости. Полная large-v3 даёт лучший результат, требует 3 ГБ места.
- Записи в `samples/` синтезированы для тестирования.

## Настройки распознавания

| Переменная | Значение | Что делает |
|---|---|---|
| `HATTAMA_PROMPT` | `on` по умолчанию, `off` отключает | Передаёт модели имена участников. Снижает ошибки в именах. В подсказке только имена собственные: длинный текст на одном языке склоняет модель к этому языку и мешает распознавать смешанную речь. |
| `HATTAMA_AUDIO_CLEAN` | `on` по умолчанию, `off` отключает | Срез гула техники и выравнивание громкости. Помогает участникам, сидящим далеко от микрофона. |

Пример: `HATTAMA_PROMPT=off ./.venv/bin/python -m uvicorn backend.main:app --port 8000`
