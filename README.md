# Протокол совещаний с контролем поручений

Система превращает запись совещания в официальный протокол и список поручений
с ответственными и сроками. Работает полностью локально, без передачи аудио и текста
во внешние сервисы — решение рассчитано на закрытый контур заказчика.

## Проблема

На совещаниях поручения раздаются устно. Секретарь записывает их вручную: часть теряется,
сроки искажаются («до конца недели» превращается в «до пятницы»), ответственный
не всегда зафиксирован. Через неделю никто не может точно сказать, кому что поручили.
Протокол пишется ещё два-три часа после совещания, а исполнение потом не контролируется.

## Что делает система

1. Расшифровывает запись совещания — русский, казахский и смешанная речь.
2. Разделяет говорящих и подставляет их имена из контекста разговора.
3. Выделяет поручения: кто, что, к какому сроку, с цитатой-источником.
4. Формирует протокол в DOCX и таблицу поручений со статусами
   «в работе / просрочено / выполнено».

## Архитектура

- `agent/` — распознавание речи и разделение говорящих, на выходе JSON с репликами
- `backend/` — извлечение поручений локальной моделью, хранение, экспорт протокола
- `frontend/` — запись и загрузка совещания, транскрипт, таблица поручений, дашборд

## Стек

Whisper (локально, Apple Silicon), эмбеддинги говорящих для диаризации,
локальная LLM через Ollama, FastAPI, SQLite, python-docx, React.
Внешние API не используются: это требование кейса.
